# xLauta7 — Portafolio profesional

Web personal de Lautaro Poggi (xLauta7), estudiante de Analista en Infraestructura Informática en ORT Uruguay y certificado CompTIA Security+ SY0-701.

Incluye experiencias de aprendizaje (OEA Cyber Challenge, PortSwigger Web Security Academy y HTB Academy), proyectos señalados como planificados y enlaces a GitHub, LinkedIn, TikTok y correo.

**Transparencia:** esta primera versión del sitio se preparó con asistencia de IA. Los proyectos y laboratorios se irán documentando por separado, distinguiendo trabajo autónomo y asistido.

## Estructura
- `index.html` — contenido
- `styles.css` — estilos responsive
- `script.js` — año dinámico
- `favicon.svg` — ícono del sitio
- `.nojekyll` — evita procesamiento Jekyll

## Ejecutar en local
Abrir `index.html` con Live Server. No requiere dependencias ni build.

## GitHub Pages
Desde Settings → Pages, seleccionar Deploy from a branch, `main`, carpeta `/(root)`.
